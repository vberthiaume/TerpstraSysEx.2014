# Lumatone Editor

## About

Introducing Lumatone Editor. The easiest way to connect to your Lumatone. Lumtone Editor is free software that allows you to create and modify mapping files for Lumatone, and save them as presets on your instrument. You can work with or without a Lumatone connected. When connected, you’ll get real-time visual feedback as you work. Every mapping allows you to define the unique characteristics of each key including key colour, midi note number and channel, and a variety of mapping-specific settings such as velocity curves, Lumatouch, polyphonic aftertouch, and expression pedal sensitivity. To learn more about Lumatone, visit [our website](https://www.lumatone.io).
